EDIT 1 — TERRAIN: 50/50 CHECKERS AND SMOOTH
================================================================================
The mode field's node bias moves; the threshold, the lattice, the doors and
the warp do not. 0.72 is SOLVED, not chosen: the visible split is not the
node split, because composite_cell_color's two doors are smoothsteps and the
scatter door opens at 0.35, well below the 0.70 threshold.

  RECIPE (4M uniform world samples; 4 iid nodes per sample through
  lattice_weight's Hermite; checker share measured as the composite's own
  mixture E[0.40·blend_door + 0.60·scatter_door], the 0.60 being E[style]
  from transition_style_at_node's 0.25/0.30/0.45 trimodal):

     e      node mean   P(field>0.70)   CHECKER SHARE   mode>=0.50   mode<0.35
    5.00      0.167         0.022            0.050        0.075        0.843
    0.72      0.581         0.309            0.500        0.658        0.143

Two riders worth knowing, both good:
  - GoL eligibility (mode >= 0.50) goes 7.5% -> 65.8% of the world. That is
    8.8x more ground where a zone may exist, and it is most of why zones are
    currently impossible to find. Edit 2 rides on top of this.
  - Sparse scatter (isolated cells, gated at mode < 0.35) survives at 14% of
    the world. It thins; it does not die.

// At each mode lattice node: roll smooth/discrete tendency.
// Quintic bias — vast majority of the world is smooth sand.
// Raw uniform [0,1] → quintic [0,1] with mean ~0.17.
fn mode_tendency_at_node(node: vec2<i32>) -> f32 {
    let seed = color_lattice_seed(node, 1u);
    let raw = hash_property(seed, 501u);
    return pow(raw, MODE_BIAS_EXPONENT);  // high exponent → vast majority smooth
}

REPLACE:
// At each mode lattice node: roll smooth/discrete tendency.
// Raw uniform [0,1] → raw^0.72, node mean 0.58 (mean = 1/(1+e)).
// The exponent is SOLVED, not tasted: half the world reads as checkers.
// The NODE split is not the VISIBLE split — composite_cell_color's doors
// are smoothsteps and the scatter door opens at 0.35, so 31% of the field
// above the 0.70 threshold delivers 50% visible checker coverage.
fn mode_tendency_at_node(node: vec2<i32>) -> f32 {
    let seed = color_lattice_seed(node, 1u);
    let raw = hash_property(seed, 501u);
    return pow(raw, MODE_BIAS_EXPONENT);
}

EDIT 4 — FOG COUPLING: FIELD 1 BECOMES THE ANCHOR
================================================================================
Field 1 currently jumps the world to golden hour at the densest setting in
the table. It takes instead the atmosphere the open outdoor world actually
wears — the same values index 0 carries, and the boot rest in
realization/state.hpp. Music is continuous, so that atmosphere is never a
rest the world visits between fields: it IS field 1's look, and every other
field is a deviation from it. The value gets ONE home in this file and both
rows read it.

    // in the dense band, 2/3/4 in the light, with small differences within each.
    // Index 0 is "no field yet" — the value at boot, before any scale is held, not
