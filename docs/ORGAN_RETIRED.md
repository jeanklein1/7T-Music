# THE RETIRED ROWS

Prose moved out of `src/console/organ_params.inc` at ORGAN_REST U5 so the
enrollment file reads as a table again. Nothing here is a live fact about the
program — **every subject below is gone.** It is kept because a retirement's
REASONING is what stops a future campaign re-adding a dial that moved nothing,
which is the failure the Mosaic section names.

**That is the same argument `docs/ORGAN.md` makes for keeping struck rows in
"What has no dial, and why"** — *"their rows are struck rather than deleted,
because the REASON each was not a dial is the register's content and outlives
the fact."* It is also this file's answer to L30: what is living here is not
the dial, it is the finding that killed it, and the next hand reaching for
that dial walks into it.

**This file is not a docket and nothing here is open.** Open state lives in
`docs/OPEN.md` (L32); the register of absences that were CHOSEN rather than
retired lives in `docs/ORGAN.md`. Three different subjects, three homes, no
copy between them.

Each heading names the row or section exactly as it was named, and the block
below it is the prose moved verbatim from its site.
