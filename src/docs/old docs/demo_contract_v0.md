# THE DEMO CONTRACT — v0 (for Jean's ratification)
Derived from Jean's ruling, 2026-07-12. Companion to theory v2;
becomes its §11 when ratified. Repo home: src/docs/.

## §1 — THE LAW
THE TEMPLATE IS THE RELATION GRAMMAR; A DEMO IS A SENTENCE IN IT.
The template fixes the RELATIONS: the four strata and their laws, the
roles (Surface as reference-frame calibrator; Body as base + normal;
Driver; the contracts), the doors, rest = identity, the analysis ->
canvas -> bank cascade, GPU sovereignty. A demo fixes the CASTS. What
matters is never how the template looks — the template has no look;
demos do.

## §2 — THE FIVE AXES (what a demo varies)
D1 THE SURFACE CAST — extent (finite of any size, or unbounded) and
   generation mode (streamed-procedural along the coordinate system,
   or generated once whole). patch_system is the first cast
   (streamed heightfield); generated-once is the declared second
   (theory §4b's reserved seat). The frame itself is castable.
D2 THE SURFACE'S VOICE — the reference frame's couplable transforms:
   geometry (the wave — currently DRIVERLESS, revival pulled by this
   contract) and color (the palette machinery and its DRIVERLESS
   siblings). A great number of things a reference can do; each is a
   pipe with a rest.
D3 THE POPULATION — which bodies exist (roster bits), their design
   tables (tiers, palettes, themes — module-resident), and, when
   M-n arrives, composition profiles.
D4 THE SKINS — every body's skin is a cast on its published
   skeleton (M-k); the pawn's will change first; the checker arc is
   the standing proof that skins swap free.
D5 THE COMPOSITION — the coupling set (which readings drive which
   pipes, per demo, canvas-side), the seed, the mood profile.

## §3 — THE FLAGSHIP PAIR (the completion test)
THE GALLERY EXHIBIT — the_board's current aesthetic, Jean's
exhibition instance. THE MUSICIAN TEMPLATE — the offered program,
demonstrating aesthetic variety to the musicians' community. The
contract is satisfied when BOTH are sentences of one template — the
wiggle test applied to the whole program: a stranger with the
template and this contract composes a demo without editing a
relation.

## §4 — THE STAGED PROGRAM (each stage pulled, none pre-built)
DEMO-1 THE CONFIG SPINE: the roster's maturity dial turns — the
   boot-time table it was born promising — inside a DEMO CONFIG (one
   named artifact: roster + seed + mood profile + design-table
   overrides v0). Two configs switchable without recompiling the
   template's identity = demo-plurality, literal.
DEMO-2 THE TERRAIN'S VOICE: revive the surface's couplable
   transforms — the amplitude pipe (the wave, rewired at last) and
   the color pipes — standing coupling laws in full (rests,
   additive-over-idleness, clamps, envelope at the call site). The
   DRIVERLESS tags retire by their own revive condition.
DEMO-3+ PULL-BASED: skin mounts per body as demos demand them; the
   generated-once surface cast when a demo demands it; M-n profiles
   when composition-variety demands them. Compositions pull designs;
   this contract is the puller.

## §5 — WHAT DOES NOT CHANGE
The relations. A demo may never edit a law, a door, a stratum, or a
contract — if a demo needs to, the template is missing a role, and
THAT is a theory amendment, not a demo option.

Ruling: one word ratifies; DEMO-1's handoff follows it.
