COMMIT [K2a] — the flee shell (stop the crowd fleeing itself)
1. DIAGNOSIS for the log: `personal_radius = 30` on every tier means
   body-to-body flee triggers at the SUM — 60 wu. With 32 agents in a
   cluster every agent is permanently fleeing every other, spending its
   small velocity budget on incoherent mutual repulsion. The shell is
   one radius with THREE expressions and they want different scales:
   sensing (flock, 30) ≠ fleeing (shoulder-scale).
2. CLASS B — beside the contact consts:
     // The social shell's flee expression is a FRACTION of its sensing
     // expression — sensing is a long-range perception, fleeing is a
     // short-range reflex. Jean-tunable.
     const FLEE_SHELL_FRAC: f32 = 0.25;   // 30+30 → 15 wu trigger
3. CLASS B — in BOTH walker kernels' body-to-body flee gate ONLY
   (not the contact spring, not the flock sense, not the point source):
     let pr = (g_self.personal_radius + og.personal_radius) * FLEE_SHELL_FRAC;
   Paste before/after at each site.

COMMIT [K2b] — the cube parting (stop the fling)
4. DIAGNOSIS for the log: the cube's point-source parting radius was
   specced as self + BUBBLE (3 + 20 = 23 wu) with an uncapped force
   proportional to the player's full speed, fed into a spring
   integrator — hence "springs too widely", in both senses.
5. CLASS B — consts:
     const CUBE_PART_RADIUS: f32 = 8.0;   // contact-scale, not bubble-scale
     const CUBE_PART_CAP: f32 = 12.0;     // max parting force magnitude
6. CLASS B — `update_cube`: the point-parting term uses
   CUBE_PART_RADIUS (replacing the bubble-derived radius) and its
   force is clamped:
     let f = min(v_ap * CUBE_PART_GAIN * falloff, CUBE_PART_CAP);
   (author CUBE_PART_GAIN 1.0 beside the others if the current term has
   no gain factor; keep the existing falloff shape). Likewise CLAMP the
   cube-vs-pawn repulsion force to CUBE_PART_CAP — it is currently
   uncapped by the T2c spec.
   WORKED EXAMPLE for the commit message: player at 15 wu/s, 5 wu from
   a cube — before: radius 23, force ∝ 15, uncapped; after: radius 8,
   force ≤ 12, falloff-shaped. Parting, not launching.
