THE DEFECT (the ninth twin). ActiveCube.cx/cz is a CPU mirror of the
GPU anchor, and it goes stale by design: the kernel's kite-release
(follow_pawn == 2u) re-anchors the cube at its TRUE present, and the
mirror is never told. Corral in anchor mode then reads the stale
mirror as its glide start, and its first upload_cube_anchor teleports
the home to where the cube was minutes ago. Kite-ON has the same
disease through the same mirror.

THE LAW. Goals may leap; values may only walk; the walk starts from
the true present — which only the kernel knows. The kernel already
holds the correct pattern (the 2u sentinel). Batch D finishes it:
the CPU authors TARGETS, the kernel walks the anchor. Afterward,
"things move because anchors moved" is literally true, and the same
target door is what music couplings drive later — one control law,
many authors.

PART A — THE MECHANISM (WGSL)
------------------------------------------------------------------
Design, stamped in chat — realize exactly:

- NEW per-cube GPU fields: target_x, target_z. Initialized :=
  anchor.xz at spawn — so at rest target == param and the glide term
  is EXACTLY zero. Rest is identity; the silence test is structural,
  not tuned.

- THE WALK (in update_cube, both modes, before the home/drift math):
      let p = (mode 0 ? anchor.xz : kite_offset.xz);
      p += (target − p) × (1 − exp(−dt / CUBE_GLIDE_TAU));
  CUBE_GLIDE_TAU: WGSL module const beside the cube behavior
  constants, value 1.1 (Jean-tunable; ≈ the old 4 s settle). No
  per-cube clocks, no from-fields; a retarget mid-flight walks from
  the present by construction.

- SENTINELS (follow_pawn):
      0  anchor-home (unchanged)
      1  kite-home   (unchanged)
      2  kite-release — EXTEND: also target := the captured anchor
      3  NEW kite-capture: offset := pos.xz − point_xz − drift.xz;
         target := offset; drift untouched; then follow_pawn := 1.
  Both toggles become exactly position-preserving even under drift.
  A mode switch cancels any in-flight glide (target := param at
  capture) — stated and deliberate.
